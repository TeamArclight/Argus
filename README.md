# ARGUS

AI-Powered Integrated Bid Compliance Verification Platform for GeM Procurement.

ARGUS analyzes tender requirements and bidder submissions, performs document intelligence and verification, evaluates deterministic compliance rules, retrieves supporting procurement knowledge through RAG, detects potential risks, and presents procurement officers with evidence-backed compliance results.
