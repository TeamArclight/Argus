# ARGUS Intelligence Service

This standalone Python package will host AI/document-intelligence capabilities for ARGUS.

Planned independent functions include:

- `extract_tender(file_path)`
- `classify_document(file_path)`
- `extract_bidder_document(file_path)`
- `retrieve_policy(query)`

Model gateways, RAG pipelines, and agent orchestration are placeholders at this stage.
No production model calls are implemented yet.
